Memory System

智能记忆系统

模拟人类记忆机制，支持衰减、召回、情感与多维评分

记忆类型

📌

短期记忆

临时会话信息，快速衰减，用于当前对话上下文

📚

长期记忆

重要信息持久存储，支持衰减与召回，可被搜索检索

💎

永久记忆

永不衰减的核心知识，始终可用，最高优先级

衰减模型

双阶段指数衰减

记忆强度随时间按指数函数递减，支持召回重激活（reactivation_boost），模拟人类遗忘-回忆机制

指数衰减 召回增强 可配置衰减率

艾宾浩斯遗忘曲线

基于艾宾浩斯遗忘曲线模型，参数 t50（半衰期）和 k（曲线陡度）可配置，更贴合人类记忆规律

遗忘曲线 t50 半衰期 k 陡度

记忆搜索流程

1

用户查询

通过 API 接收搜索请求，支持关键词搜索和语义搜索

2

混合搜索

并行执行向量搜索（语义相似度）和关键词搜索（SQLite LIKE），结果融合排序

3

三维评分计算

综合重要性（importance）、时间衰减（temporal）、语义相关性（relevance）三维评分

4

结果返回

按综合评分排序返回搜索结果，支持分页和过滤

Quick Start

快速开始

三步启动，即刻体验

1 安装依赖

# 后端依赖
pip install -r requirements.txt

# 拉取模型 (Ollama)
ollama pull qwen3-vl:8b
ollama pull nomic-embed-text

2 启动后端

python main.py

# 或使用 Conda 环境
# 2.启动后端(Conda环境).bat

3 启动前端

cd frontend
npm install
npm run dev

# Windows 一键启动:
# 1.1.启动前端(含控制服务)(Conda).bat

环境要求

✅ Python 3.10+

✅ Node.js 18+

✅ Ollama (推荐) 或其他 LLM 服务

最小配置

models:
  main:
    provider: ollama
    model: qwen3-vl:8b
    enabled: true
  embedding:
    provider: ollama
    model: nomic-embed-text
    enabled: true

Deployment
